# Algorithms and financial conventions

|Method|Purpose / mathematical basis|Python implementation|Inputs → outputs|Validation / limits|
|---|---|---|---|---|
|EMI|P r / (1−(1+r)^−n), monthly r=annual percentage/1200; zero-rate P/n|backend/finance.py, log1p/expm1 for stability|Principal, rate, months → monthly instalment|Known numerical example, zero rate, invalid tenure tests; no fees/irregular dates|
|Personal capacity|DTI=(existing monthly EMI+proposed EMI)/net monthly income|financials|Monthly finances → DTI, disposable income|50% policy ceiling; missing/zero denominators return null|
|Business ratios|DSCR=cash available/(existing annual service+12 EMI); interest cover=EBITDA/(existing interest+first-year contractual proposed interest); current assets/liabilities; total debt/equity; net and EBITDA margins|financials|Annual accounts → ratio set|Known-value tests; first-year interest proxy, EBITDA interest cover, no amortized interest schedule|
|Expected loss|PD×LGD×EAD|assessment|Synthetic ML PD, principal, reviewed collateral → loss|Identity test; no calibrated horizon. Unsecured LGD=.65. Secured recovery=sum(value×(1−haircut)), LGD floor .05, no collateral=.65 and manual review. LTV uses gross market value|
|Logistic Regression|Log odds are linear in standardized features, L2 regularization|sklearn Pipeline/StandardScaler/LogisticRegression; C grid .1,1,10|Six features → default probability|5-fold stratified CV, 20% held-out test; synthetic labels encode nonlinear probability, not bank outcomes|
|Random Forest|Bagged trees, randomized split candidates|sklearn RandomForestClassifier, 100 trees, depth 4/8, min leaf 5/15|Six features → probability|Same CV; no feature scaling needed|
|XGBoost|Additive boosted decision trees minimizing logistic loss|XGBClassifier, 100 trees; depth 2/4, learning rate .05/.1|Six features → probability|Same CV/test. Selection by training CV AUC, never test AUC|
|SHAP|Additive attribution to reference model output|LinearExplainer for logistic, TreeExplainer for forest/XGBoost|Saved feature vector/model → per-feature contributions and base|Additivity test for all 3 models. Logistic/XGB log odds; forest class-1 probability; not causal inference|
|Isolation Forest|Random partition isolation; shorter paths indicate unusual inputs|sklearn IsolationForest, contamination .08, seed42|Feature vector → negative score_samples and flag|Prediction exercised; no fraud accuracy claim|
|Fuzzy matching|Weighted edit/token similarity plus exact identity override|RapidFuzz WRatio, threshold60|Name/identity → ranked candidates|Exact identity test, human review required, no calibrated match probability|
|Network linkage|Exact shared normalized address/phone edges and stored ownership relationships|Python pairwise comparison|Customers/relationships → node and edge table|Persistent relationships and evidence; O(n²), local scale only|
|Scenario stress|Income/revenue multipliers, expense shock, rate shift, collateral shock, explicit PD multiplier|stress_profile + assessment|Scenario → new capacity, PD/LGD/loss|Base assessment is not overwritten; multiplier affects policy output, SHAP explains raw model PD|
|Monte Carlo|One-factor Gaussian latent Z=sqrt(rho)F+sqrt(1−rho)e; default when Z<Phi^-1(PD)|NumPy, scipy.special.ndtri|Exposures, correlation, trials → mean, 95% VaR/tail mean, histogram|Seed42 reproducibility, 100–20,000 trials; homogeneous correlation, no amortization or macro calibration|
|Loan optimization|Constrained candidate search over current/36/60/84 months. Max principal under capacity and secured recovery≥80%, tie-break RAROC|Python explicit enumeration|Facility/financials → alternatives and best|Capacity DSCR1.2/DTI.5; funding6%, capital12%; no fee/tax/prepayment model|
|Audit chain|SHA256 canonical event payload plus preceding hash|security.audit/verify|Mutation → chained audit event|Tampering test; no protection against complete privileged rewrite or suffix truncation|

ML dataset: 1,800 independent synthetic rows, seed42, six inputs, Bernoulli outcomes sampled from a documented logistic generator in src/data.py. Split 1,440 training/360 test. Scaling is fitted inside folds. Metrics: ROC-AUC, PR-AUC, precision/recall/F1 at .30, confusion matrix, Brier and calibration bins. Candidate selection uses training CV only. No fairness, external validity, time-series validation or regulatory certification is inferred.
